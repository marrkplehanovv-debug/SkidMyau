# Модели ИИ-ротации

Сюда кладутся обученные веса (см. `tools/ai/README.md`):

* `angles-v2.skm` + `angles-v2.json` — предсказание следующей тик-дельты;
* `aimpoint-v1.skm` + `aimpoint-v1.json` — точка прицеливания на грани.

Без них работает bootstrap-режим. Пока файлов нет, папка существует только
чтобы путь `assets/skidmyau/ai/` был предсказуемым.
